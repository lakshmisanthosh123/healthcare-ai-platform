# @healthcare-ai-platform/types

Shared TypeScript types for the project.

Exports:

- `DateInput` and `DateFormatOptions` from `DateFormatter`
- `Patient` interface
- `Doctor` interface
- `Appointment` interface
- `Common` utilities types
- `ApiResponse<T>` generic response type

Usage:

```ts
import { Patient, Appointment } from "@healthcare-ai-platform/types";
```
