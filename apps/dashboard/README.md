# Healthcare analytics dashboard

The authenticated dashboard contains five report pages:

- `/dashboard` — executive KPIs, monthly revenue, monthly appointments, and patient growth.
- `/dashboard/doctors` — patients per doctor, patient rating, revenue per doctor, and appointment status.
- `/dashboard/patients` — gender and age distribution, new patients, and returning patients.
- `/dashboard/revenue` — monthly and daily invoice totals, payment method, and outstanding balances.
- `/dashboard/appointments` — status, no-show comparison, appointment trends, and peak booking hours.

The executive dashboard embeds the configured Power BI report with
`powerbi-client-react`. Its short-lived embed token is generated by the
authenticated FastAPI endpoint; Power BI service credentials never leave the
server, and the token is kept in browser memory only for embedding. The
remaining report pages use React SVG charts backed by
`GET /dashboard/analytics`, which queries the Django models in the configured
database.

Set the Power BI server environment variables described in
[`backend/README.md`](../../backend/README.md). Never use `VITE_` variables for
Power BI credentials. Configure the Power BI semantic model to use the
PostgreSQL database and make sure its data source credentials or gateway are
available to the Power BI service. Apply Django migrations before using invoice
and rating analytics; the development launcher runs migrations automatically.
Admin/staff can enter appointment invoices through the API, and patients can
rate their completed appointments.

Reporting definitions:

- Revenue is total invoiced amount, including unpaid invoices. Outstanding is invoice amount minus amount paid. Payment-method totals show amounts received.
- Values are shown in INR.
- New patients have their first completed appointment in that month; returning patients have a later completed visit.

All authenticated modules share a responsive sidebar/header and language selector from `@healthcare-platform/ui`.
